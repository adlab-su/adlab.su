🛡️ Меры по обеспечению конфиденциальности (Privacy Practices)
Вкладка в консоли: «Конфиденциальность» / Privacy
Все разрешения в Manifest V3 тщательно выверены. Скопируйте соответствующие обоснования в поля консоли разработчика Chrome.
1. Описание основного назначения (Single Purpose Description)
Tablo Tab превращает страницу новой вкладки в персонализированную экспресс-панель со стилями Fluent Mica и Metro Classic, настраиваемыми плитками закладок, рабочими столами, интерактивными виджетами (часы, погода, заметки, курсы валют) и безопасной облачной синхронизацией через Google Диск.
2. Обоснования для каждого разрешения (Permission Justifications)
activeTab
Используется для получения URL-адреса, заголовка и фавиконки активной вкладки при клике на иконку расширения, позволяя пользователю сохранить открытый сайт в закладки без запроса постоянного доступа к истории браузера.
contextMenus
Используется для добавления пункта «Добавить страницу в Tablo Tab» в контекстное меню правой кнопки мыши на веб-страницах и ссылках для быстрого добавления сайтов на выбранный рабочий стол.
identity
Используется исключительно для опциональной авторизации пользователя в его личном Google Диске (OAuth2) для создания резервных копий и синхронизации закладок между устройствами.
storage
Используется для надежного локального сохранения пользовательских настроек, рабочих столов, плиток закладок, заметок To-Do и конфигураций виджетов на устройстве пользователя.
tabs
Используется для создания скриншотов-превью сохраняемых страниц (chrome.tabs.captureVisibleTab), определения текущего URL в окне добавления плитки и пакетного открытия закладок рабочего стола в новых вкладках.
unlimitedStorage
Необходимо для предотвращения ошибок квоты памяти при локальном сохранении графических превью сайтов, кэшированных фавиконок и пользовательских фоновых обоев высокого разрешения.
Доступ к хостам (Host permissions)
Доступ к хостам необходим для автоматической загрузки фавиконок и логотипов для любых сайтов, которые пользователь добавляет на панель, а также для получения актуальных данных встроенных виджетов (прогноз погоды с API Open-Meteo и курсы валют/криптовалют с открытых финансовых API).
3. Использование удаленного кода (Remote Code)
Выберите пункт: «Нет, я не использую удаленный код» (No, I do not use remote code).
Все скрипты расширения упакованы локально в архив в строгом соответствии с требованиями Manifest V3.
