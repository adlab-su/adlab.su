Политика конфиденциальности расширения Tablo Tab

Официальный регламент использования пользовательских данных для Google Chrome Web Store

01 // Общие принципы конфиденциальности

Браузерное расширение Tablo Tab — Экспресс-панель (ID в Chrome Web Store: jmnpkejnlfmkckbmnanopjglbbmogeck) создано авторской лабораторией AD LAB. Наш основополагающий принцип — полная автономность. Расширение не собирает, не анализирует, не продает и не передает третьим лицам личные данные пользователя.

02 // Локальное хранение данных (chrome.storage.local)

Все пользовательские данные, включая закладки, рабочие столы (Workspaces), заметки блокнота To-Do, историю пользовательских настроек и кэшированные иконки сайтов, сохраняются исключительно в изолированном локальном хранилище вашего браузера.

✓ У разработчика отсутствует серверная база данных.
✓ У нас нет доступа к списку ваших сайтов или содержимому заметок.

03 // Облачное резервное копирование Google Диск (Опционально)

Функция облачного резервного копирования является добровольной. При её активации подключение осуществляется напрямую между вашим браузером и серверами Google по протоколу OAuth2. Токен авторизации и архив бэкапа сохраняются в защищенную изолированную папку приложения на вашем личном Google Диске. Никакие промежуточные сервера AD LAB в этом процессе не участвуют.

04 // Обоснование разрешений Manifest V3

activeTab & tabs:

Используются исключительно в момент, когда пользователь нажимает «Добавить текущую страницу в Tablo Tab», для считывания заголовка и URL активной вкладки. Фонового мониторинга посещаемых сайтов нет.

contextMenus:

Используется для интеграции пункта «Сохранить в Tablo Tab» в контекстное меню правой кнопки мыши для быстрого сохранения страниц.

storage & unlimitedStorage:

Необходимы для надежного локального хранения плиток, пользовательских обоев и настроек оформления без риска переполнения лимитов браузера.

Доступ к сетевым хостам (<all_urls>):

Используется исключительно для прямого скачивания официальных фавиконок (логотипов) добавляемых сайтов и получения публичных котировок/погоды от открытых поставщиков (Open-Meteo).

05 // Отсутствие трекеров и аналитики

Tablo Tab не содержит Google Analytics, Яндекс.Метрики, рекламных баннеров или систем сбора телеметрии.

01 // Privacy Architecture & Principles

The Tablo Tab — Speed Dial & Widgets extension (Chrome Web Store ID: jmnpkejnlfmkckbmnanopjglbbmogeck) is developed by AD LAB. We enforce zero telemetry: the extension does not monitor, collect, or share personal user data with developers or third parties.

02 // Client-Side Storage (chrome.storage.local)

All user data — including workspaces, bookmarks, notes, and appearance settings — is saved strictly inside your browser's private local sandbox.

✓ The developer maintains no database servers.
✓ We have zero visibility into your bookmarks, notes, or browsing behavior.

03 // Google Drive Cloud Backup (Optional)

Cloud synchronization is entirely optional. When activated, communication runs directly between your browser and Google's official OAuth2 endpoints. Backups are stored in an isolated private app folder on your personal Google Drive account.

04 // Manifest V3 Permissions Justification

activeTab & tabs:

Used only when the user explicitly triggers "Add to Tablo Tab" to extract title, URL, and favicon of the active tab. No background browsing tracking.

contextMenus:

Adds a right-click "Save to Tablo Tab" shortcut for streamlined bookmarking.

storage & unlimitedStorage:

Allows robust offline persistence for tiles, custom wallpapers, and cached logos without browser quota exceptions.

Host Permissions (<all_urls>):

Required exclusively to fetch official high-resolution site favicons and pull open public weather/market feeds (Open-Meteo).

05 // Zero Telemetry Guarantee

Tablo Tab contains no Google Analytics, trackers, advertising SDKs, or background telemetry agents.
