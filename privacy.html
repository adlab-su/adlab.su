01 // Общие положения

Лаборатория AD LAB (adlab.su) и авторские программные продукты (включая расширение для браузера Tablo Tab) строятся на принципах уважения частной жизни. Мы не собираем, не храним и не продаем персональные данные пользователей.

02 // Локальное хранение данных

Все ваши закладки, конфигурации рабочих столов, смарт-виджеты (часы, погода, курсы), заметки To-Do и пользовательские настройки сохраняются исключительно в локальном хранилище вашего браузера (chrome.storage.local) на вашем персональном компьютере.

У разработчика нет внешних баз данных, трекеров или серверов сбора телеметрии.

03 // Синхронизация через Google Диск (опционально)

Если вы используете облачную синхронизацию, обмен данными происходит строго и напрямую между вашим браузером и вашим личным аккаунтом Google Диск по официальному протоколу Google OAuth2. Никакие промежуточные серверы не используются, и разработчик не имеет доступа к вашему диску или резервным копиям.

04 // Использование разрешений браузера

  • activeTab и tabs — получение адреса, заголовка и фавиконки текущего сайта при добавлении в закладки и создание превью страниц;
  • contextMenus — быстрое добавление страниц в Tablo Tab через меню правой кнопки мыши;
  • storage и unlimitedStorage — сохранение ваших закладок и кэша обоев/логотипов на диске без ошибок переполнения квоты;
  • Доступ к хостам (<all_urls>) — загрузка официальных логотипов сайтов и публичных данных для виджетов (прогноз погоды Open-Meteo, котировки валют).

05 // Партнерские ссылки (Affiliate Links)

Некоторые предустановленные плитки маркетплейсов или популярных сервисов могут содержать стандартные партнерские/реферальные метки. Переход по ним является обычным веб-переходом, не собирает персональных сведений и не передает разработчику никаких данных о вашей активности.

06 // Правила программы Chrome Web Store

Мы строго соблюдаем Правила программы для разработчиков Chrome: пользовательские данные не продаются третьим лицам, не монетизируются и не используются для оценки кредитоспособности.

01 // General Overview

AD LAB (adlab.su) and our software products (including the browser extension Tablo Tab) are built with privacy-first principles. We do not collect, monitor, store, or sell any personal information.

02 // Local Data Storage

All your bookmarks, virtual workspace layouts, smart widgets (Clock, Weather, Rates), sticky To-Do notes, and custom preferences are stored strictly in your browser's local memory (chrome.storage.local) on your own device.

We do not operate any external tracking servers, telemetry databases, or analytics services.

03 // Google Drive Backup (Optional)

If you choose to use the cloud backup feature, data synchronization occurs directly between your browser and your private Google Drive account via Google's official OAuth2 API. The developer never has access to your Google account or your files.

04 // Permissions Usage

  • activeTab & tabs — capture active page title, URL, and favicon when saving a bookmark, and generate local snapshot previews;
  • contextMenus — enables 1-click page saving to Tablo Tab via the right-click context menu;
  • storage & unlimitedStorage — prevents quota errors when storing website thumbnail previews, cached icons, and custom desktop wallpapers;
  • Host Permissions (<all_urls>) — fetch official website favicons/logos and retrieve live public data for widgets (Open-Meteo weather forecasts and currency rates).

05 // Affiliate & Referral Links

Certain pre-configured tiles for popular online marketplaces or web tools may contain standard affiliate/referral parameters. Clicking these links does not collect or transmit any personal data to the developer.

06 // Chrome Web Store Policy Compliance

We strictly adhere to the Google Chrome Web Store Developer Program Policies: no user data is sold, transferred for unrelated purposes, or used to evaluate creditworthiness.
