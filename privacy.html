Политика конфиденциальности сайта adlab.su

Соответствие Федеральному закону РФ № 152-ФЗ «О персональных данных» и нормам GDPR

01 // Назначение сайта и общие положения

Сайт adlab.su является официальной публичной витриной авторской инженерной лаборатории AD LAB (Главный конструктор: Штыков А.Д.). Мы уважительно относимся к конфиденциальности каждого посетителя и строим архитектуру наших ресурсов по принципу «Privacy by Design» и нулевого избыточного сбора данных.

02 // Использование Cookies и локального хранилища (localStorage)

Сайт adlab.su не использует рекламные, коммерческие или следящие cookie-файлы. Для удобства работы пользователя браузер сохраняет исключительно технические настройки в изолированном локальном хранилище (localStorage):

adlab_themeВыбранная тема оформления (тёмная или светлая)
adlab_langВыбранный язык интерфейса (RU или EN)
adlab_cookie_consentОтметка о подтверждении согласия с регламентом

Указанные ключи сохраняются исключительно в браузере на вашем устройстве, никогда не передаются на внешние сервера и могут быть удалены вами в любой момент через настройки браузера.

03 // Сбор и обработка персональных данных

Мы не собираем ваши персональные данные, историю посещений, параметры устройств, контактные книги и не осуществляем цифровое профилирование посетителей. Мы не встраиваем сторонние коммерческие счетчики или маркетинговые пиксели.

04 // Хостинг и безопасность соединений

Сайт размещен на статической инфраструктуре GitHub Pages с поддержкой шифрования по протоколу HTTPS и сертификатами центра сертификации Let's Encrypt. Серверные системные журналы технического доступа (HTTP access logs) могут обрабатываться инфраструктурой GitHub в соответствии с глобальной политикой безопасности GitHub Inc.

05 // Политики для отдельных программных решений

Для авторских браузерных расширений и программных утилит (в частности, расширения для Chrome Tablo Tab) действует отдельная расширенная политика конфиденциальности, описывающая права доступа API браузера:

01 // Purpose & General Scope

The website adlab.su is the official public showcase of AD LAB (Chief Engineer: Shtykov A.D.). We deeply value privacy and engineer all our systems following the principle of Privacy by Design and zero extraneous data collection.

02 // Cookies & LocalStorage Usage

adlab.su does not use advertising, marketing, or tracking cookies. We strictly use client-side localStorage to remember your selected preferences:

adlab_themeUI appearance theme (light or dark)
adlab_langInterface language (RU or EN)
adlab_cookie_consentPolicy notice acknowledgement flag

These values are stored solely within your local browser sandbox, are never dispatched to external endpoints, and can be cleared at any time in your browser settings.

03 // Personal Data Collection

We do not collect personal identifiers, device telemetry, contact books, or browsing history, and we do not perform audience profiling or sell visitor telemetry to advertising networks.

04 // Hosting & Transmission Security

This site is hosted statically on GitHub Pages with TLS/HTTPS encrypted connections provided by Let's Encrypt certificates. Low-level server access logs may be maintained by GitHub Inc. for security and operational integrity.
